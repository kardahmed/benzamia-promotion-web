# Politique de sécurité

Ne publiez pas de vulnérabilité, de secret ou de donnée client dans une issue publique.

## Secrets

Tous les secrets sont stockés dans GitHub Environments ou dans le gestionnaire de secrets du fournisseur. Les fichiers `.env`, clés privées et exports CRM sont interdits dans Git.

## Signalement

Utiliser les signalements privés de sécurité GitHub lorsqu'ils sont activés, ou contacter le propriétaire du dépôt par un canal privé validé.
